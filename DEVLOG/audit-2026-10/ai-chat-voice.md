### 1.2 Live chat (`/api/chat`) data flow
1. Rate limit (new): 20/min and 150/h per IP. Input capped at 2,000 chars. History is capped at the last 6 messages × 4,000 chars, and only user/assistant roles are forwarded. Province must be BC, AB or ON.
2. Contact scraping: an email or phone number found in the message (or `contactInfo`) is sent to the Twenty CRM webhook (`TWENTY_WEBHOOK_URL`, hard-coded default) and to Discord (`DISCORD_LEAD_WEBHOOK_URL`). This runs in parallel with the LLM call and is now awaited before the response.
3. Lender intelligence: `resolveLenderFromQuery` + `resolveGeographicUnderwritingQuery` (`lib/ai/lenderIntelligence.ts`, reading `data/canadianLendersData.ts`, 147 lenders). When a lender matches, its dossier and grounding instructions are appended to the system prompt.
4. System prompt: brokerage facts, rental and GDS/TDS rules, and (new) compliance rules. Benchmark rates now come from the same feed as `/api/rates` (`RATES_FEED_URL`, then the local file, then the embedded snapshot, cached 5 minutes) instead of hard-coded numbers.
5. Provider chain, all non-streaming:
   1. OpenRouter `deepseek/deepseek-v4.1-flash`, falling back to `deepseek/deepseek-chat`. Both IDs were verified on OpenRouter's public `/models` list on 2026-10-12.
   2. Gemini `gemini-2.5-flash` via REST v1beta.
   3. NVIDIA NIM `meta/llama-3.2-11b-vision-instruct`.
   4. The deterministic lender or geographic dossier.
   5. A static brokerage contact message.
6. `<think>` / reasoning tags are stripped, the PII-redacted query goes into an in-memory audit buffer (100 entries per instance), and the API returns `{reply, message, matchedLender}`.

## 2. Fixed

New shared helpers (both new files are in owned directories):
- `lib/ai/request-guards.ts` provides:
  - `rateLimit()`: best-effort in-memory sliding window per IP and bucket.
  - `tooManyRequests()`.
  - `requireAdmin()`: Firebase ID token check plus `isAdmin(uid)`, the same pattern as `/api/run`. Firebase is imported lazily.
  - `redactPII()` and `maskPhone()`.
  - Verified with a node harness: 20 of 22 requests allowed then 429 with `retryAfter`, and emails/phones redacted.
- `lib/voice/twilio-signature.ts`: `isValidTwilioRequest()` computes HMAC-SHA1 over the URL plus sorted params, tries several candidate public URLs, compares in constant time, and fails closed when the token or signature is missing. Verified against Twilio's documented example vector (output `0/KCTR6DLpKmkAf8muzZqo1nDgQ=` matches).
